## Stage 1: factorial representation and history control

Four configurations: C40/O1, C40/O10, C60/O1, C60/O10. C40 uses 0.1 and 1 second; C60 adds 10 seconds. O1 sorts by the complete 1-second activity vector, then the 0.1/1-second vector; O10 uses the complete 10-second activity vector, then the full three-window vector. Endpoint IDs never enter sorting or prediction. C40/O10 intentionally uses 10-second information only for slot ordering; this is stated as part of the factorial definition.

All four have the same 25 legacy non-port fields, raw targets, training treatment (Balanced), five inherited expert hyperparameters, seeds, splits and fixed voting weights from the recorded C60/O10 predictor for the corresponding stage. Holding the weights fixed prevents timing-dependent weight tuning from confounding the factorial contrast. Report uniform voting, LR and RF on the same predictions as controls. Three temporal estimator seeds and two signature folds; existing C40/O1 and C60/O10 expert arrays are reused only after exact feature and split equality checks. Two crossed conditions are newly fitted. G/C outputs and a model hash are saved before V scoring. Existing per-stage C60/O10 remains the reference predictor; no winner is chosen from new V results.

History control uses the same two signature splits. For each fold, every mapped target is assigned its fixed A/G/C/V role. Other unlabelled packet records receive a deterministic random assignment with probabilities equal to the four role fractions. Exclusive mode gives each packet to exactly one role's ring, preventing any raw history packet from being shared between roles. A marginal-density control uses one uniform random number per unlabelled packet and includes it in each role if u < role fraction; overlaps are permitted. Mapped target records are restricted to their own role in both modes. Both controls use the same global logical clock, original temporal reset boundaries and target set. Prior queries occur before push. Neither thinning control is a realistic new traffic session; changing density is a limitation, and the matched marginal control helps separate it from exclusivity. Compare the unchanged full-history reference and both controls; report realized packet allocation/overlap and changed inputs. Fixed hyperparameters, stage weights and Balanced treatment apply to each refit.

The cohort's capture and class are perfectly confounded. Summarize context statistics by capture and audit cross-role history allocation; do not interpret a capture classifier as independent evidence about causal attack features. Removing shared histories alone does not establish capture-independent generalization.
